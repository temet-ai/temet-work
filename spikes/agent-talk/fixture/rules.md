# How the arbiter rules
1. The issue's "Done when" and "Always" lines decide. "Scope" says where "Done when" applies.
2. A reviewer blocks only for an end state not met, a bug introduced, or code that does not fit.
3. A claim about the code that nobody has shown is not evidence. Say so, and say what would settle it.
4. The ruling is AUTHOR (merge as it is) or REVIEWER (change required), with one reason and, for REVIEWER, the exact change.
