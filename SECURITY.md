## Reporting a vulnerability

Report it privately through GitHub: on [temet-ai/temet-work](https://github.com/temet-ai/temet-work),
open the **Security** tab and choose **Report a vulnerability**. Please do not open a public
issue for it.

Say what you found, how to reproduce it, and which version (`temet-work --version`) and platform
you used. We aim to reply within a week. Fixes ship in the next release rather than as
patches to older ones.

## Supported versions

Only the latest release is supported.
